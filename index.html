Blinders.ai

Turns a single YouTube URL into an end-to-end AI content analysis: it scrapes the video, runs machine-learning models to summarise the content and read its sentiment, then forecasts how the video will perform over the next six months across views, likes, comments, and engagement. The result is a quick read on what a video is about and where it is headed.

  • Next.js
  • Supabase
  • Python
  • Mistral-7B / flan-t5 on Modal

Virtual Economy - SEA

A web-based multiplayer economic tycoon game set in Southeast Asia. Players buy land on a generated map, build factories, hire employees, and run multi-level commodity supply chains, trading finished goods on a shared marketplace while climbing a net-worth leaderboard. It runs as a server-authoritative modular monolith so game state stays consistent across every player.

  • NestJS
  • Next.js
  • Postgres
  • Redis
  • BullMQ
