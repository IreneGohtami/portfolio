# Portfolio

My personal portfolio — a single-page site showcasing a selection of projects
I've built, each with a short demo video and the technologies behind it.

Live site: https://irenegohtami.github.io/portfolio/

## Projects

- **Tuinet V2** — a rebuild of TUI's internal airline and travel booking
  management platform, with a modern dashboard, RBAC user management, reporting,
  and bulk refund / cancellation processing.
- **Holiday Web & CMS** — the Kenya Airways Holidays landing site plus a headless,
  multi-tenant CMS that white-labels one frontend across holiday brands.
- **GDS connector (PNR Lookup)** — looks up flight bookings across Amadeus and
  Sabre from one search box, and ships as MCP servers for AI assistants.
- **Blinders.ai** — turns a YouTube URL into an AI content analysis: scrape,
  summarise, read sentiment, and forecast six-month engagement.
- **Virtual Economy - SEA** — a web-based multiplayer economic tycoon game set in
  Southeast Asia, built as a server-authoritative modular monolith.
- **Pawtner** — a pet breeder finder for browsing puppies, favouriting, viewing
  breeder profiles, and reserving a puppy.
- **Pacman** — a classic Pac-Man clone written from scratch in C++ on a custom
  2D tile and sprite engine.
